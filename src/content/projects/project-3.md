# JavaScript Game

The concept behind the Shots Clicker Game was to transform a foundational JavaScript exercise into a playful, character-driven experience. Instead of a typical clicker game, I created a humorous world where taking “shots” earns points and unlocking celebrities boosts your score. The intention was to show how even basic coding tools — arrow functions, event listeners, and DOM manipulation — can build a miniature game universe filled with personality. The motivational quotes that occasionally fly across the screen add unpredictability and charm, making the experience feel more dynamic and rewarding. This project reflects my instinct to layer humor, narrative, and visual energy into even the simplest technical tasks.

Key features and accomplishments include:

- **Event-Driven Mechanics:** Arrow functions trigger real-time score changes and animations.
- **Celebrity Upgrades:** Increasing multipliers add progression and strategy.
- **Dynamic UI Updates:** DOM manipulation ensures smooth and responsive gameplay.
- **Motivational Quote System:** Random animated messages enhance user engagement.
- **Balanced Game Economy:** Thoughtful scoring and upgrade pacing create a satisfying loop.
