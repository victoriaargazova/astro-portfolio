# Lifestyle Guide Website

Surviving Off-the-Grid was the very first website I ever coded, and it represents the beginning of my journey into web design. The goal of the assignment was to create a survival guide, but instead of following traditional wilderness themes, I reinterpreted “off the grid’’ as an escape from **corporate burnout**. I imagined a guide written for women who want to disconnect from hustle culture and rediscover joy through softness, slowness, and self-directed rituals. The tone became playful and supportive — less about survival and more about reclaiming your time and identity in a world obsessed with productivity.  

Visually, I leaned into a muted collage aesthetic, using soft textures, poster-like backgrounds, and scrapbook-inspired compositions to reflect the emotional warmth of starting fresh. Even though the HTML and CSS were not yet refined, the project taught me how design and code can work together to express mood and narrative. It became a safe space to experiment, make mistakes, and discover my natural affinity for collage-driven visual storytelling.

## Key features and accomplishments include:

- **Conceptual Reinterpretation:** Transformed a survival guide into a feminist, lifestyle-focused narrative about escaping burnout.
- **Muted Collage Style:** Used soft colors and layered textures to create a scrapbook-like aesthetic that feels comforting and personal.
- **Foundational HTML/CSS Work:** Built a complete website layout using only beginner techniques — no JavaScript or frameworks.
- **Poster-Style Visual Compositions:** Background images and torn-paper edges established the tone despite early technical limitations.
- **Narrative Flow:** Organized the guide into approachable “tips” that mix humor, encouragement, and self-care.
