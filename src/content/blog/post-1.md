Getting started with Astro surprised me in the best way. When I opened my first project, I felt something I hadn’t felt in a long time while coding: *relief*.  
Everything finally had a place — components in one folder, pages in another, and layouts tying everything together without unnecessary complexity.

As a design student, structure matters almost as much as visuals. Astro’s approach instantly made sense to me. Components look clean and readable, and the `.astro` file format feels natural instead of overwhelming.

## What Stood Out Immediately

- The folder structure felt intuitive  
- Layouts finally clicked for me  
- I wasn’t drowning in JavaScript  
- The fast dev server made experimenting fun  

I didn’t expect to prefer a framework this quickly, but Astro fits the way I already think: modular, organized, and visually driven.

It’s still early in the journey, but for the first time, I’m genuinely optimistic about understanding code — not just using it.
