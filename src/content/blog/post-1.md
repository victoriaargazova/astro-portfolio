# Starting Astro and Finally Feeling Hopeful About Code

When I first opened Astro, I felt something I hadn’t felt in a while when writing code: *relief*.  
Everything had a place. Everything had a purpose. Components lived in one folder, pages in another, and layouts tied it all together without the usual chaos.

As a design student, structure matters to me almost as much as visuals. Astro's way of separating concerns immediately made sense. I liked how components looked clean and readable, and how `.astro` files could mix HTML, JS, and styling without turning into a mess.

## What Stood Out Immediately

- **The folder structure felt intuitive**  
- **Layouts finally clicked for me**  
- **I wasn’t drowning in JavaScript**  
- **The instant feedback loop with the dev server made experimenting fun**

I didn’t expect to prefer a tool so quickly, but Astro feels like the first framework that supports the way I already think:  
*modular, organized, and visually driven.*

It’s still early, but for the first time, I’m optimistic about getting better at code.
